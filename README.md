# roblox-game

Проект Roblox-игры. Код хранится в `src/` и синхронизируется с Roblox Studio через [Rojo](https://rojo.space).

## Первая настройка (один раз на компьютер)

1. Установи [Roblox Studio](https://create.roblox.com), [VS Code](https://code.visualstudio.com) и [Git](https://git-scm.com/downloads).
2. Установи **Rokit**. Это менеджер инструментов: он ставит Rojo, Selene и StyLua нужных версий.
   - Windows (PowerShell):
     ```powershell
     Invoke-RestMethod https://raw.githubusercontent.com/rojo-rbx/rokit/main/scripts/install.ps1 | Invoke-Expression
     ```
   - macOS:
     ```sh
     curl -sSf https://raw.githubusercontent.com/rojo-rbx/rokit/main/scripts/install.sh | bash
     ```
   После установки перезапусти терминал.
3. Открой терминал в папке проекта и установи инструменты из `rokit.toml`:
   ```sh
   rokit install
   ```
   Rokit спросит, доверяешь ли ты авторам инструментов. Ответь «да».
4. Установи плагин Rojo в Studio:
   ```sh
   rojo plugin install
   ```
   Если Studio была открыта, перезапусти её.
5. Открой папку проекта в VS Code: **File → Open Folder**. VS Code предложит установить рекомендованные расширения (Rojo, Luau LSP, StyLua, Selene). Согласись.

## Как работать каждый день

1. Запусти сервер Rojo. Это можно сделать в терминале VS Code:
   ```sh
   rojo serve
   ```
   Или нажми на иконку Rojo в нижней панели VS Code.
2. В Studio открой своё место (для начала подойдёт шаблон **Baseplate**).
3. Во вкладке **Plugins** нажми **Rojo → Connect**.
4. Пиши код в VS Code. Каждое сохранение файла сразу появляется в Studio.
5. Тестируй игру в Studio кнопкой **Play**.
6. Закончил кусок работы — сохрани его в Git:
   ```sh
   git add .
   git commit -m "Что сделал"
   git push
   ```

## Что где хранится

| Папка в проекте | Куда попадает в Studio | Для чего |
|---|---|---|
| `src/server` | `ServerScriptService.Server` | Серверная логика: деньги, урон, сохранения |
| `src/client` | `StarterPlayer.StarterPlayerScripts.Client` | Клиент: интерфейс, управление, эффекты |
| `src/shared` | `ReplicatedStorage.Shared` | Общие модули: настройки, утилиты |

Карта, модели и интерфейс, собранные мышкой в Studio, в файлы **не** попадают. Они хранятся в самом месте. Сохраняй его через **File → Publish to Roblox**.

### Тип скрипта задаётся расширением файла

| Имя файла | Что создаётся в Studio |
|---|---|
| `Name.server.luau` | `Script`: выполняется на сервере |
| `Name.client.luau` | `LocalScript`: выполняется у игрока |
| `Name.luau` | `ModuleScript`: подключается через `require` |
| папка с `init.luau` внутри | `ModuleScript`, а остальные файлы папки становятся его детьми |

## Как устроена игра

Симулятор сотрудника склада. Четыре операции: приёмка в блоке К4, раскладка и сборка на мезонине в блоке К2 и карщики на тягачах.

### Меню операций

При входе в игру открывается меню: игрок выбирает, на какой операции работать. Открыть меню снова можно клавишей **M** или кнопкой «Операция» слева. После выбора показывается инструкция к этой операции (кнопка «Инструкция» открывает её снова), а задание в панели справа ведёт только по выбранной работе.

Справа на экране всегда видна панель сотрудника: должность, рейтинг, качество, баланс, операция и текущее задание. Сверху экрана — только уведомления.

| Операция | С какого рейтинга |
|---|---|
| Приёмка | сразу |
| Раскладка | 2 500 |
| Сборка | 2 500 |
| Карщик | 4 000 |

Правила:
- Действия других операций закрыты. Например, стол у старших дают только на приёмке, тягач — только карщику.
- Сменить операцию можно, когда руки свободны и задание закончено. При уходе с приёмки стол освобождается, при уходе с карщиков тягач уезжает на стоянку.
- Операции не зависят друг от друга и от других игроков: задания генерируются для каждого отдельно. Раскладчик получает свою новую тару, сборщику всегда есть что собрать, карщику на погрузке выдают его собственные тары. Тары, которые игроки сдают в буферы, увозит NPC.
- Названия, требования и тексты инструкций лежат в `src/shared/Operations.luau`.

Столов приёмки на карте 15. Чтобы новичкам всегда хватало столов, поставь в **Game Settings → Places → Max Players** не больше 15.

### Приёмка

1. Игрок появляется в раздевалке и переодевается в форму у шкафчика (удерживать E).
2. Проходит пост охраны: без формы барьер не пускает.
3. В зоне выдачи оборудования получает ТСД у сотрудника за компьютером (удерживать E).
4. Выбирает в меню операцию «Приёмка». У стола старших получает номер рабочего стола (удерживать E). Фиолетовая стрелка ведёт к столу.
5. Занимает стол (E). Грузчик на погрузчике привозит палет: 500–1000 товаров, в основном одной категории.
6. Кликает ТСД по QR-коду палета.
7. Берёт пустую тару в большом буфере пустых тар, катит к столу и ставит на одно из трёх мест (E у стола).
8. Кликает ТСД по верхней коробке на палете: коробка встаёт на стол. Вскрывает её (удерживать E).
9. Кликает по коробке: товар достаётся и пикается. Потом кликает по таре: товар уходит в неё, игроку платят цену пика этого товара. Тара наполняется на глазах.
10. Пустую коробку разрезает (удерживать E) и бросает картон в тару для картона (E у тары): общую в начале ряда или свою, поставленную у стола. В тару влезает 20 коробок. Свою полную тару для картона игрок откатывает в буфер мусора. Общую, как только она заполнится, сразу меняют на пустую, поэтому ждать никого не нужно.
11. Полную тару с товаром (500 шт.) везёт на товарный буфер в зону её категории.

У каждого товара своя цена пика (от 1 ₽ за носки до 4.50 ₽ за фен, в среднем около 2.60 ₽), и раз в минуту цены немного меняются. Табло у каждого стола показывает средний пик по всем товарам и средний пик игрока за этим столом. Деньги считаются с копейками.

Товар разных категорий нужно класть в разные тары. Назначение тары задаёт первое, что в неё положили: товар или картон. За каждый товар не той категории на буфере с вероятностью 50% штрафуют на цену 10 его пиков. Текущее задание всегда видно в панели справа.

### Мезонин в блоке К2: раскладка и сборка

В К2 пускают с рейтинга 2 500: через турникет у входа или через ворота для техники на севере. Там трёхэтажный мезонин: на каждом этаже две категории (1 этаж — Химия и Красота, 2 — Общак и Электроника, 3 — Детское и Зоотовары). На этажи ведут лестница с западной стороны и грузовой подъёмник в северо-восточном углу: у пульта жмёшь E «Выбрать этаж», и открывается меню с кнопками этажей (можно и клавишами 1, 2, 3). Ячейки подписаны адресами «этаж-ряд-ячейка», например 2-05-12.

- **Раскладка.** Тары с товаром сами приезжают в зону раскладки у мезонина (западная сторона К2): их возят карщики и NPC-тягачи с товарного буфера К4. В зоне всегда стоит не меньше 4 тар, так что раскладчик никого не ждёт. Жмёшь E у тары «Взять на раскладку». ТСД говорит, какой товар в какую ячейку: кликаешь ТСД по ячейке, и туда уходит вся пачка этого товара. Пустую тару возвращаешь в зону пустых тар мезонина.
- **Сборка.** В зоне пустых тар мезонина берёшь тару на сборку, на ТСД приходит заказ из 3–6 товаров с разных этажей. Кликаешь ТСД по нужным ячейкам, собранный заказ сдаёшь в зоне отгрузки и получаешь бонус.

За каждой ячейкой закреплён один товар (он подписан на ячейке и стоит на полке), а запас не кончается. Поэтому раскладка и сборка не зависят друг от друга: сборщику не нужно ждать раскладчиков, и двое игроков никогда не делят одну ячейку. Настройки — `Config.Mezzanine`.

### Карщики: тягачи и паровозы из тар

С рейтинга 4 000 выдают права на тягач. Тягач берут на оранжевой стоянке в центральном проходе (E), ездят на W/S и A/D, выходят пробелом. Если выйти и не вернуться за минуту, тягач сам уедет на стоянку.

Карщики работают по заявкам диспетчера. Заявка говорит, что везти, сколько тар (3–6), откуда и куда. Она видна в панели справа, стрелка ведёт к погрузке, потом к месту сдачи.

| Заявка | Погрузка (синяя зона) | Куда везти | ₽ за тару |
|---|---|---|---|
| Товар на мезонин | в проходе между товарным буфером и буфером мусора К4 | зона раскладки у мезонина К2 | 20 |
| Картон на утилизацию | между буфером мусора К4 и дорогой | утилизация в северо-западном углу К2 | 15 |
| Пустые тары в К4 | у зоны пустых тар мезонина | приём пустых тар у буфера К4 | 10 |

Из К4 в К2 едут по жёлтой линии вдоль северной стены, через ворота для техники.

Все действия за рулём делаются одной подсказкой E на самом тягаче, она меняется в зависимости от места:
- на погрузке нужного вида — «Прицепить тару»: каждое нажатие цепляет новую тару, выданную лично тебе;
- в месте сдачи — «Сдать паровоз»;
- на стоянке — «Сдать тягач».

Оплата и бонусы:
- За заявку, довезённую целиком, — бонус 30 ₽. Если сдать меньше тар, платят только за тары.
- Примерно треть заявок срочные: если успеть за 150 секунд, бонус ×3. Отсчёт идёт в панели справа.
- За каждую тару — 5 очков рейтинга.
- После сдачи сразу приходит новая заявка.

Если карщик не довёз паровоз за 5 минут, заявка снимается, тары отцепляются и их довозит NPC. Тары, которые игроки сдают в буферы (товар на товарный буфер, картон в буфер мусора, пустые в зону мезонина), через 3 минуты увозит NPC на своём тягаче. Поэтому склад не встанет, даже когда карщиков нет в игре. Настройки — `Config.Tugger`.

### Админ-панель (временная, для теста)

Кнопка **«Админ»** слева видна только в Studio и владельцу игры. Обычным игрокам панель недоступна: сервер проверяет права на каждое действие.

Что умеет панель:
- **Игрок.** Стрелками `<` `>` выбираешь, кого менять (по умолчанию себя). Ниже видны его баланс, рейтинг, качество и операция.
- **Баланс, рейтинг, качество.** Впиши число и нажми «Поставить» или жми быстрые кнопки (+1000 ₽, рейтинг 2500 и 4000 и т. п.).
- **Персонаж.**
  - Надеть форму, выдать ТСД.
  - Освободить руки: убрать тару, товар и картон.
  - Снять с операции.
  - Новый палет на стол.
  - Убрать тягач.
  - Скорость 40 или обычная.
- **Телепорт.** В раздевалку, к столу старших, к буферам, на любой этаж мезонина, на отгрузку, к стоянке тягачей и на утилизацию.
- **Склад.** NPC сразу увозит все тары из буферов, цены пиков меняются прямо сейчас.
- **Настройки.** Вместимость тары, штрафы за пересорт, задержка палета, оплата раскладки, сборки и карщиков, скорость тягача, таймеры NPC и другое. Изменения действуют до перезапуска сервера. Чтобы поменять насовсем, правь `Config.luau`.

В чате работает команда `!rating 5000`: она ставит рейтинг и тоже доступна только админам.

Если сохранение включено, выданные деньги и рейтинг тоже сохранятся. Список настроек и точек телепорта лежит в `src/shared/AdminConfig.luau`. Когда панель станет не нужна, удали `src/server/AdminPanel.luau`, `src/client/AdminPanel.client.luau` и `src/shared/AdminConfig.luau`, а из `Main.server.luau` убери две строки с `AdminPanel`.

### Рейтинг и сохранение

Рейтинг состоит из двух частей (настройки — `Config.Rating`):
- **Очки.** Копятся за работу: верный пик +1, тара сдана на буфер +20, палет разгружен +50, тара с картоном в мусор +10. Каждый пойманный пересорт −20. От очков зависят должность (Стажёр → Кладовщик → Старший кладовщик → Бригадир → Начальник смены) и доступ в блок К2: с 2 500 очков турникет начинает пропускать.
- **Качество.** Доля пиков без ошибок за последнее время (одна ошибка сразу минус 2%). Даёт надбавку к цене пика: от 98% +15%, от 95% +10%, от 90% +5%.

Должность видна над головой, а рейтинг, качество и надбавка — в панели справа.

Деньги, рейтинг и качество сохраняются между заходами в DataStore. Чтобы сохранение работало при тесте в Studio, место должно быть опубликовано (**File → Publish to Roblox**), и в **Game Settings → Security** должен быть включён **Enable Studio Access to API Services**. Без этого игра работает, но прогресс не сохраняется (в Output будет предупреждение).

### Своя карта вместо заготовки

Заготовку строит скрипт при запуске, поэтому в режиме редактирования её не видно. Чтобы сделать карту своей:
1. Нажми **Play**, в Explorer выдели `Workspace → Map` и скопируй (Ctrl+C).
2. Останови игру, выдели `Workspace` и нажми Ctrl+Shift+V (Paste Into).
3. Теперь карта хранится в самом месте: её можно двигать, перекрашивать, достраивать. Модель называется `Map`, поэтому скрипт больше не строит заготовку.

Скрипты находят нужные детали по тегам (их видно и можно менять в Properties, раздел Tags). Если строишь что-то с нуля, не забудь теги:

| Тег | На чём | Зачем |
|---|---|---|
| `LockerSpawn` | `SpawnLocation` | Где появляются игроки. Остальные точки появления отключаются |
| `Locker` | деталь | Шкафчик, где переодеваются |
| `SecurityGate` | деталь | Барьер на посту охраны: пропускает только игроков в форме |
| `K2Gate` | деталь | Турникет и ворота в блок К2: пропускают игроков с рейтингом из `Config.Rating.K2Access` |
| `Cell` | деталь с атрибутами `Address`, `Category`, `Floor` | Ячейка стеллажа на мезонине |
| `LiftStop` | деталь с атрибутом `Floor` | Площадка подъёмника на этаже |
| `LiftPanel` | деталь с атрибутом `Floor` | Пульт подъёмника: открывает меню выбора этажа |
| `K2EmptyCarts` | деталь на полу | Зона пустых тар мезонина: тара на сборку и возврат пустых |
| `ShippingZone` | деталь на полу | Зона отгрузки собранных заказов |
| `TuggerDepot` | деталь на полу | Стоянка тягачей: здесь берут и сдают тягач |

| `TrainDrop` | деталь на полу с атрибутом `Kind` | Куда сдают паровоз: `goods` — зона раскладки, `cardboard` — утилизация картона, `empty` — приём пустых тар |

### Оформление карты

Карта в минималистичном стиле:
- Материалы с фактурой: шлифованный бетон на полу, оштукатуренные светло-серые стены, тёмный металлический потолок, рифлёный стальной настил на мезонине, плитка в раздевалке. Внизу стен тёмный плинтус и фиолетовая фирменная полоса.
- Шкафчики в раздевалке: графитовый корпус, дверцы из шлифованной стали с вентиляцией, ручками и номерами. Скамейки — дерево на стальных ножках.
- Сотрудники — настоящие персонажи Roblox в форме склада: сотрудник выдачи ТСД сидит в кресле, старший смены стоит за стойкой, водители погрузчика и NPC-тягача сидят за рулём. Внешность (цвет кожи, причёска) — в `src/server/Npc.luau`.
- Столы приёмки — верстаки: светлая столешница на стальных боковинах, полка с коробками, коврик, монитор с включённым экраном, клавиатура и подставка для ТСД. Стол старших — стойка с деревянной столешницей и монитором.
- Тары: серые пластиковые стенки с рёбрами, стальной каркас с ободом, поворотные колёса с дисками, ручка с резиновой накладкой и тёмные таблички с надписями.
- Тягач: оранжевый корпус на раме, капот с решёткой и фарами, руль, сиденье со спинкой, защитная дуга с мигалкой, стоп-сигналы, колёса с дисками.
- Склад, раздевалка и коридор охраны под крышей, под потолком ряды светодиодных ламп.
- Вывески — тёмные скруглённые панели с цветной полосой. Они светятся сами и хорошо читаются издалека.
- У каждой зоны на полу есть яркая рамка и крупная надпись: «ПУСТЫЕ ТАРЫ», «ПОГРУЗКА · КАРТОН», название категории и т. д.
- Свет ровный и нейтральный, без пересвета, с мягкими тенями и лёгкой цветокоррекцией (`Map/Environment.luau`).
- Шрифт везде современный: Builder Sans.

Цвета, материалы и надписи зон меняются в одном файле — `src/server/Map/Theme.luau`.

**Перепрыгнуть нельзя.** Раздевалка и коридор охраны под потолком. Стеклянный барьер поста охраны идёт от пола до потолка. Над ограждением блока К2 до самой крыши стоит невидимая стена: ни пост, ни К2 не перепрыгнуть, даже встав на стойки турникета.

### Свои текстуры, картинки товаров и значки категорий

Готовые картинки нельзя положить в код: Roblox показывает только то, что загружено в твой аккаунт. Порядок такой.

**1. Картинки товаров** (например, фото или иконка фена на коробке):
1. Подготовь PNG 512×512, лучше с прозрачным фоном.
2. Загрузи: Studio → **View → Asset Manager → Images → Import** (или [create.roblox.com](https://create.roblox.com) → Development Items → Decals).
3. В Asset Manager нажми на картинку правой кнопкой → **Copy Asset ID**.
4. Допиши его четвёртым аргументом в `look(...)` у товара в `src/shared/Config.luau`: `look("Block", Vector3.new(0.5, 1, 1.1), Color3.fromRGB(40, 40, 45), "rbxassetid://ТВОЙ_ID")`.

Картинка появится на товаре в руке, в таре и на полках мезонина.

**2. Значки категорий** (рисуются на полу товарного буфера рядом с названием). Загрузи картинку так же и впиши ID в категорию в `Config.luau`:
```lua
{ Id = "Beauty", Name = "Красота", Color = ..., Icon = "rbxassetid://ТВОЙ_ID", Items = { ... } }
```

**3. Текстуры пола, стен, настилов** (например, эпоксидный пол или бетон):
1. В Studio открой **Model → Material Manager**.
2. Создай вариант материала (кнопка **+**) на основе SmoothPlastic и назови его, например, `WarehouseFloor`.
3. В его свойствах укажи картинки текстуры: ColorMap, а по желанию NormalMap и RoughnessMap. Можно взять бесплатные PBR-текстуры (например, с ambientcg.com) и загрузить их, как в пункте 1.
4. Впиши имя варианта в таблицу `VARIANTS` в `src/server/Map/Theme.luau`: `Floor = "WarehouseFloor"`.

Так же можно сделать текстуры стен (`Wall`), настилов мезонина (`Deck`) и крыши (`Roof`).
